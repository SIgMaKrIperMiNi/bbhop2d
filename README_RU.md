# BHOP — проект для сборки Android APK

В архиве находится подготовленная копия вашей игры `bbhop.py` (как `main.py`), конфигурация Buildozer и локальный рецепт Pygame.

## Что уже подготовлено

- Сохранён исходный код игры.
- `bhop_save.json` на Android будет записываться в приватную папку приложения через `android.storage.app_storage_path()`.
- Настроены SDL2, альбомная ориентация, полноэкранный режим и архитектура arm64-v8a.
- Добавлена GitHub Actions workflow для облачной сборки APK.
- Добавлен рецепт pygame 2.6.1 с известными обходными исправлениями Android-сборки.

## Как получить APK с телефона

1. Создайте новый репозиторий на GitHub. Назовите его, например, `BHOP-Android`.
2. Распакуйте этот ZIP на телефоне.
3. Загрузите **все файлы и папки внутри** `BHOP_Android_Project` в корень репозитория. Важно: папка `.github` тоже должна попасть в репозиторий.
4. Откройте вкладку **Actions** в репозитории.
5. Выберите workflow **Build BHOP APK** и нажмите **Run workflow** (или дождитесь запуска после загрузки файлов).
6. Дождитесь завершения задачи. Если она завершилась успешно, откройте её страницу, найдите раздел **Artifacts** и скачайте `BHOP-debug-APK`.
7. Распакуйте скачанный архив — внутри должен быть APK.

## Важные замечания

- Это подготовленный проект, а не уже собранный APK.
- Pygame на Android требует нативной сборки SDL2 и C-расширений. Поэтому успешная компиляция ещё не доказывает, что игра запускается на конкретном телефоне.
- Если GitHub Actions завершится ошибкой, откройте задачу и пришлите сюда **первую красную ошибку из Build debug APK** или скачанный build log. Я помогу исправить конфигурацию.
- После успешной сборки APK всё равно нужно установить и проверить на устройстве: запуск, сенсорное управление, звук и сохранение рекордов.
- Сейчас используется Android API 35 (приложение должно запускаться и на Android 16); это не означает, что APK уже протестирован на Android 16.

## Состав проекта

- `main.py` — игра BHOP.
- `buildozer.spec` — настройки Android-пакета.
- `p4a-recipes/pygame/__init__.py` — локальный рецепт Pygame.
- `.github/workflows/build.yml` — облачная сборка через GitHub Actions.
